## 🔧 第一步：建仓库，就像新建一个文件夹

操作很简单，网页上点几下就行：

1. 登录 GitHub，点击页面右上角的 “+” 号，选择 “New repository”。
2. 填写仓库信息：
   - **Repository name**：起个名字，比如 `qa-learning-notes` 或 `test-portfolio`。
   - **Description**：简单描述，例如“我的测试开发学习笔记与练习项目”。
   - **可见性**：选 **Public**（公开），这样面试官才能看到你的作品集。
   - 勾选 **“Add a README file”**：这会让仓库自动创建一个 `README.md` 文件，这就是你的“笔记本首页”。
3. 点击 **“Create repository”**，仓库就建好了。

---

## ✍️ 第二步：写 README，就是写“笔记本”的封面和目录

`README.md` 是别人打开你仓库看到的第一样东西，相当于你这本笔记本的封面和目录。它用 Markdown 语法来写，这是一种很简单的标记语言，用纯文本就能实现排版效果。

你不需要学很多，记住几个最常用的就够了：

- **标题**：用 `#` 表示，`#` 越多标题层级越小。例如 `# 我的学习笔记`。
- **列表**：用 `-` 或 `*` 开头，用来罗列要点。
- **粗体**：用 `**文字**` 包住，用来强调关键内容。
- **代码**：用反引号 `` `代码` `` 包住，用来标注命令或术语。
- **链接**：用 `[显示文字](链接地址)` 的格式来添加超链接。

一个适合你当前阶段的、简单的 README 模板可以是这样：

```markdown
